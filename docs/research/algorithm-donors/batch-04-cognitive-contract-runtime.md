# ARCH-ALG-04 — Cognitive Lifecycle / Contracts / Tools / Runtime Tests

## Scope

Fourth donor batch: constitutional super-engine, cognitive loop, typed response models, tool schemas, multi-horizon state engine, repository/data bridges, integrated analyzers, synchronization code, and extensive tests.

## Canonical conclusion

This batch provides several of the strongest reusable patterns for WOLF15 Sentient: **constitutional pipeline flow, typed contracts, tool descriptors, cognitive lifecycle, multi-horizon state analysis, and executable test patterns**.

### Top donor principles

1. **Constitutional Super-Pipeline**
   Hard precondition gate → analysis → typed proposal → constitutional authority.
2. **Typed Contract Family**
   No public subsystem boundary should rely on untyped dictionaries where a versioned contract is feasible.
3. **ToolDescriptor / JSON Schema Registry**
   Tools are exposed minimally and only after capability/authority resolution.
4. **General Cognitive Lifecycle**
   Perception → context/memory → reasoning → planning → evaluation → Control Kernel → result/action → episode.
5. **Multi-Horizon State Alignment**
   Useful for SCRS only after telemetry calibration; a single observation is never perfect alignment.
6. **Test Corpus Pattern**
   Boundary, edge, concurrency, replay, error-path, and installed-package checks are reusable testing disciplines.

### Required corrections

- No model/prompt as sole policy enforcement.
- No scaffold declared ready merely because folders exist.
- No single observation = 100% alignment.
- No placeholder secret fallback.
- Health != readiness.
- No direct cognitive action authority.
- Analysis log != learning.
- Uncalibrated weighted score != confidence.
- Random integrity != telemetry.
- Integration-test pass != production-ready.
