# Repository agent guidance

Baca [WOLF15 Sentient Principle](docs/architecture/persona/WOLF15_SENTIENT_PRINCIPLE.md) bersama [persona versioning](docs/architecture/persona/persona-versioning.md) untuk pekerjaan persona CP1.1. Status dokumen DESIGN_CANON; tidak memberi authority untuk publish, merge, deploy, persistence atau aktivasi. Instruksi user dan policy host yang berlaku tetap menentukan scope.

Pertahankan CP1.1-DESIGN-001 dan ALG-REG-001 beserta bindings historis. Lifecycle profil penerus mengikuti receipt DESIGN-002 yang terikat manifest; tanpa receipt PASS/FROZEN yang valid, perlakukan sebagai candidate dan lakukan review/freeze baru. Jangan memuat seluruh Principle sebagai system prompt; gunakan subset dan binding yang eksplisit. Bukti lokal, CI, provider dan runtime tidak boleh saling menggantikan. Donor adalah sumber studi, bukan pemberi authority.
